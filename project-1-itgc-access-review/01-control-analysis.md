
# Control Analysis: Access Review Process

## Control Name

Access Review Process

## Control Description

Quarterly privileged access reviews.

## Control Area

Privileged Access Management / User Access Review

## Control Objective

To ensure that users with privileged access continue to have a valid business need for that access.

## Risk Addressed

Users may retain unnecessary or excessive privileged access, increasing the risk of unauthorized system changes, data exposure, or misuse of administrative rights.

## Expected Evidence

To prove this control is working effectively, the following evidence would normally be expected:

- List of privileged users reviewed
- Date of review
- Reviewer name
- Review decisions
- Approval/sign-off
- Evidence of access removal where required

## Possible Failure Points

1. Not all privileged accounts are included in the review.
2. Review is performed using an outdated user list.
3. Review is performed but not approved.
4. Review evidence is not retained.
5. Review is not completed quarterly.
