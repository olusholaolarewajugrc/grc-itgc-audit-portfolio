# Project 1: ITGC Audit Simulation — Access Review Process

## Project Overview

This project is based on a simulated GRC lab environment. The purpose is to practice evaluating an IT General Control related to privileged access reviews.

The control reviewed was named **Access Review Process**, and it focused on quarterly privileged access reviews.

## Control Area

**IT General Controls — Privileged Access Management**

This control falls under ITGC because it relates to the review and monitoring of privileged access rights.

## Control Reviewed

**Control Name:** Access Review Process  
**Control Description:** Quarterly privileged access reviews  
**Control Status:** Partially Effective  

## Audit Objective

To evaluate whether privileged access is reviewed periodically and whether the review process is properly documented and approved.

## Risk

If privileged access is not properly reviewed, users may retain excessive or unauthorized access. This could lead to unauthorized system changes, data compromise, or misuse of administrative privileges.

## Simulated Audit Procedure

The following audit procedure was simulated:

1. Reviewed the control description.
2. Identified the control area as privileged access management.
3. Assessed the meaning of the control status: “Partially Effective.”
4. Identified possible failure points in the control process.
5. Documented an audit-style finding with risk, root cause, and recommendation.

## Key Finding

The privileged access review process appears to be partially effective, which may indicate incomplete review coverage or lack of documented approval evidence.

## Recommendation

The organization should implement a formal privileged access review process that includes:

- A complete list of privileged users
- Quarterly review completion tracking
- Manager or system owner approval
- Evidence retention for audit purposes

## Skills Demonstrated

- ITGC control identification
- Privileged access risk analysis
- Audit reasoning
- Control effectiveness assessment
- Audit finding documentation
- Risk-based recommendation writing

## Disclaimer

This is a simulated audit project created for learning and portfolio purposes. It does not represent an audit of a real organization.
