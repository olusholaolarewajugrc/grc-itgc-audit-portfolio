# Project 4 – Change Management Control Review

## Objective

To evaluate whether changes to production systems are properly authorized, tested, documented, and implemented according to organizational change management procedures.

## Control Information

- Framework: COBIT
- Reference: BAI06
- Control Owner: DevOps
- Frequency: Per Change
- Effectiveness: Effective

## Audit Scope

The review focused on a sample of production system changes to determine whether:

- Changes were formally requested.
- Changes were approved before implementation.
- Testing was completed before deployment.
- Rollback procedures were documented.
- Evidence was retained.

## Audit Result

PASS

The control was operating effectively. Sampled changes contained documented approvals, testing evidence, and implementation records.
