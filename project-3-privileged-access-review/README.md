# Project 3: Privileged Access Review

## Project Overview

This project simulates an IT General Controls (ITGC) review focused on privileged access management.

The objective is to determine whether privileged accounts are appropriately assigned, reviewed, approved, and monitored.

## Control Area

Privileged Access Management

## Control Objective

To ensure privileged access is granted only to authorized personnel and reviewed periodically.

## Risk

Excessive or unnecessary privileged access may allow unauthorized changes to systems, data, and security configurations.

## Audit Focus

This review focuses on:

- Identification of privileged accounts
- Approval of privileged access
- Periodic access reviews
- Evidence supporting access appropriateness
- Detection of excessive privileges

## Skills Demonstrated

- ITGC auditing
- Access management review
- Privileged account analysis
- Risk assessment
- Evidence evaluation
- Audit finding development
