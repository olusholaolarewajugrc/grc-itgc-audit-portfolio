# Lessons Learned — User Termination Control Review

## Key Lessons From This Project

### 1. Access removal is as important as access provisioning

Organizations often focus on granting access but may overlook timely removal of access when employees leave.

---

### 2. Controls depend on process design

Even if IT intends to remove access, the control can fail if Human Resources and IT do not have a formal communication process.

---

### 3. Missing evidence may indicate control weakness

Auditors do not simply ask whether a process exists.

They review evidence to determine whether controls operate effectively.

---

### 4. Root causes matter

The active account itself was not the main issue.

The larger issue was the absence of a formal HR-to-IT workflow.

---

### 5. Audit findings require structure

Using Condition, Criteria, Cause, Effect, and Recommendation (CCCEE) helped organize observations and recommendations clearly.
