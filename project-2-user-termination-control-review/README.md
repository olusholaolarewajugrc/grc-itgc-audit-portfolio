# Project 2: User Termination Control Review

## Project Overview

This project simulates an IT General Controls (ITGC) review focused on user termination controls.

The objective is to assess whether user accounts belonging to terminated employees are disabled or removed in a timely manner after employment ends.

## Control Area

User Access Management / Termination Controls

## Control Objective

To ensure that access for terminated employees is removed promptly to prevent unauthorized access to company systems and sensitive information.

## Risk

If terminated users retain access after leaving the organization, they may be able to access, modify, delete, or misuse company data.

## Audit Focus

This review focuses on:

- Whether terminated employees were identified
- Whether their system access was removed on time
- Whether evidence exists to support timely deprovisioning
- Whether any exceptions were found

## Skills Demonstrated

- ITGC understanding
- User access review
- Termination control testing
- Evidence review
- Audit finding documentation
- Risk-based thinking
