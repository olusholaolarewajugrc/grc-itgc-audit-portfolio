# Project 5 – Multi-Factor Authentication (MFA) Control Review

## Objective

To evaluate whether Multi-Factor Authentication (MFA) is implemented and operating effectively to protect user accounts and reduce the risk of unauthorized access.

## Control Information

* Framework: ISO 27001
* Reference: A.5.17
* Control Owner: IT Security
* Frequency: Continuous
* Effectiveness: Effective

## Audit Scope

The review focused on determining whether:

* MFA is enabled for user accounts.
* MFA is enforced for privileged accounts.
* Authentication controls are monitored.
* Users are required to provide multiple forms of authentication before access is granted.

## Audit Result

PASS

The MFA control was operating effectively. Evidence reviewed indicated that MFA was implemented and continuously enforced for applicable user accounts.
